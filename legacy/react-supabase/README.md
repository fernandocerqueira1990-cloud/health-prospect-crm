Snapshot dos arquivos da prova de conceito anterior à migração para Laravel.

Esta pasta é somente uma referência histórica. O código não integra o novo núcleo,
não deve ser publicado e não recebe novas funcionalidades. A versão original também

nenhuma chave ou credencial real está versionada.

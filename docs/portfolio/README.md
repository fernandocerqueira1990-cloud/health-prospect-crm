## O que este case demonstra

- modelagem e desenvolvimento de uma aplicação CRM real;
- Laravel, PHP, PostgreSQL e Redis;
- autenticação, RBAC e auditoria;
- pipeline comercial, leads, campanhas e relatórios;
- importação CSV/XLSX com validação e deduplicação;
- testes automatizados e análise estática;
- CI com GitHub Actions;
- hardening de segurança e preparação para produção;
- documentação e evolução incremental por sprints.

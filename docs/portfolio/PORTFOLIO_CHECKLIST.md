# Portfolio Maintenance Checklist

Checklist de manutenção da apresentação pública do **Health Prospect CRM**.

## Antes de divulgar uma nova versão

- [ ] README representa a arquitetura atual.
- [ ] screenshots não contêm dados reais ou sensíveis.
- [ ] diagrama de arquitetura está atualizado.
- [ ] roadmap reflete o estado real das sprints.
- [ ] links internos do README e de `docs/` estão válidos.
- [ ] `.env`, credenciais, dumps, backups e chaves privadas não estão versionados.
- [ ] documentação de segurança está atualizada.
- [ ] CI está passando.
- [ ] Pull Request descreve mudanças e validações.

## Periodicamente

- [ ] revisar About e Topics do GitHub.
- [ ] atualizar screenshots após mudanças visuais relevantes.
- [ ] atualizar arquitetura quando novas integrações entrarem em produção.
- [ ] revisar `CONTRIBUTING.md` e `.github/SECURITY.md`.
- [ ] arquivar ou remover documentos internos obsoletos que não agreguem rastreabilidade.

Este checklist existe para manter o repositório útil tanto como código-fonte quanto como case técnico de portfólio.
